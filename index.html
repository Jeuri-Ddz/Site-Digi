WS 01

Introducció als Sistemes Operatius

Tipos de sistemas operativos

  • SO Propietarios Windows, macOS
    • Soporte oficial
    • Ecosistema integrado
    • Coste elevado
    • Código cerrado
  • SO Libres Linux: Ubuntu, Fedora, Debian, SUSE
    • Gratuito
    • Comunidad activa
    • Personalización total
    • Curva de aprendizaje

Rutas de archivos

  • Absoluta — desde la raíz: /home/user/doc
  • Relativa — desde la posición actual: ./doc

Comandos básicos

  • Comandos que nos permiten navegar, listar y gestionar archivos desde una terminal
  • pwd mkdir ls cd touch echo rm

Máquinas virtuales

  • SO simulado dentro de otro SO, aislado del real
  • Uso: probar sistemas, aislar entornos, sin arriesgar el equipo
WS 02

Control de versions

01

Què ens proporciona?

  • Desenvolupar col·laborativament en equip sobre el mateix codi
  • Històric de canvis, qui els ha realitzat, quan...
  • Etiquetatge de versions
  • Comparar, revertir codi de versions
02

Git

És el sistema de control de versions distribuït més utilitzat en el món. Va ser creat al 2005 per Linus Torvalds. A partir d'aquest, s'han creat diverses plataformes com Github, que adapten les funcionalitats a una interfície web, allotjant repositoris al núvol, fent-los accessibles desde qualsevol lloc.

03

Google Suite

  • Desat automàtic
  • Traçabilitat
  • Historial de versions
  • Col·laboració eficient
  • Revisió de canvis (què, qui, quan)
04

Flux de treball

Alguns dels termes més importants en el flux de treball de control de versions de Git.

  • Repositori -> Carpeta especial on es desa el projecte
  • Branch -> Una versió independent del repositori
  • Commit -> Un canvi específic al codi
  • Merge -> Combinar canvis de diferents branches

Ejemplo práctico

fun main() {

        print("Ingresa el primer numero: ")
        val num1: Float = readln().toFloat()

        print("Ingresa el segundo numero: ")
        val num2: Float = readln().toFloat()

        print("Ingresa un numero para elegir la operacion:\n1. Suma \n2. Resta\n3. Division\n4. Multiplicar\n\nIngresa el numero: ")
        val num3: Int = readln().toInt()

        if (num3 == 1) {
          print("El resultado es: " + (num1 + num2))
        }
        if (num3 == 2) {
          print("El resultado es: " + (num1 - num2))
        }
        if (num3 == 3) {
          print("El resultado es: " + (num1 / num2))
        }
        if (num3 == 4) {
          print("El resultado es: " + (num1 * num2))
        }

      }

WS 05

UX/UI wireframe

01

UX / UI

UX · User Experience

Se centra en la lògica, estructura i funcionalitat.

Defineix a qui va dirigida la pàgina web i com s’organitza la informació.

És la part que no veiem però sí sentim.

UI · User Interface

És la part visual de l’estructura definida per la User Experience.

Defineix la identitat: colors, tipografia i altres elements visuals.

03

Evolució del disseny

El disseny comença amb un sketch simple. Després es crea un wireframe com a base, hi apliquem el mockup i finalitzem amb un prototip funcional.

04

Arquitectura de software

És el pla global que defineix on va cada component i com es comunica amb els altres.

L’escalabilitat i la seguretat depenen de l’arquitectura.

05

Model client-servidor

És el patró d’arquitectura que fa servir la World Wide Web.

  1. El client sol·licita informació per mostrar-la a la pantalla.
  2. El servidor processa la consulta i accedeix a les dades necessàries.
  3. El servidor retorna la resposta amb els arxius a mostrar.
